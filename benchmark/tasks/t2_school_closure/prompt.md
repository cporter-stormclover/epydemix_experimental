An influenza-like epidemic (R0 = 1.6, latent period 2 days, infectious period
3 days) spreads in Italy from 2026-10-01 to 2027-06-30, using all four
contact layers. A three-week school closure cuts school contacts by 90%.
Which start date for the closure, among the 18 weekly dates from 2026-12-01
to 2027-04-01, most reduces the epidemic peak?

Use 20 simulations per scenario. Save the no-closure scenario as
outputs/baseline.epx and the closure scenarios under outputs/closure.epx
(one sweep, or one bundle per start date whose name contains the date).
Report the best start date and how much it lowers the peak compared with no
closure.
